## 1. Purpose

A recurring Monday-morning operations retrospective covering the week that just ended (Mon–Sun, America/New_York), across two service lines — Managed Technology (MT, Support tickets + Auvik network monitoring) and Cybersecurity (Event tickets + SentinelOne alert stream). v4.0 adds PagerDuty monitoring data for both teams and a second, company-visible one-page team report. ## 6. Data gotchas (learned in production)

1. **Timezone:** all timestamps (Halo + PagerDuty) UTC; bucket by ET (−4h in EDT). Server-side date filters use ET-shifted UTC bounds.
2. **`NonBillableTime` is useless** (`"-0"`). Billability from `ChargeCode` only.
3. **Halo pagination trap (CORRECTED 8/31):** `halo_get` path `Tickets` caps at 50 rows and **ignores `page_no` entirely** on the ticket path (page 2 = same rows; `record_count` maxes at 50). Setting `page_no` does NOT help. Split date windows until each returns <50 (§5.2), or use `ticketidonly: true` for counts, or `get_tickets` (pages honestly) for the open queue. `domain: "opps"` is the one `halo_get` path that pages correctly.
4. **`enddate` bare-date is exclusive** — use `"YYYY-MM-DD 23:59:59"`.
5. **Closure attribution:** use `closure_agent_id`, not `agent_id` (most closed events sit on Unassigned). Closure execution is highly concentrated (8/31: Karenke 47/47 support, Patrick 7/7 events; 9/7: Karenke 40, Patrick 19 of 61 — Patrick's 19 include a Tue 9/1 19:47 ET batch of 14 events and a Fri 9/4 batch of 5) — it reflects who runs the close step, not workload. Report the assigned-agent split alongside it for workload.
6. **`Report/9` truncation at 500k** only cuts `table_html`; `rows` parses intact.
7. **reportlab Tc leak:** char spacing set in a text object persists across BT/ET — reset to 0 inside the text object before `drawText`, or all subsequent text renders wide and columns overlap.
8. **Logo:** use the official pre-decoded S-mark PNGs from the `simvay-brand-styling` skill assets (`simvay-mark-white.png` / `-teal.png`, 206×256, transparent) via `drawImage(..., mask="auto")`. **The synced skill path carries a hash prefix** — locate it with `glob("/root/.claude/skills/synced/**/simvay-brand-styling/assets/simvay-mark-white.png", recursive=True)`, never hard-code. Do NOT hand-draw a substitute mark and do NOT retype logo data URIs from context (base64 corrupts) — Ryan flagged a hand-drawn mark on 8/24. White mark on gradient/teal only.
9. **PagerDuty truncation** (see §5.5) — per-week pulls for SentinelOne, and since ~9/7 the `limit` param caps at 100: paginate every call with `offset` until `truncated=false`.
10. **S1 title client-tag is not always numeric** — `SIMVAY-NFR (nfr)` and `Polaris Career Center (OH)` break a `\(\d+\)` parser; use `\(([^)]+)\)`.
11. **✓ glyphs:** Carlito has no U+2713 and ZapfDingbats' check renders as a hollow box under poppler — draw checkmarks as a 2-segment stroked path instead (this bit again on 9/7 in a section TITLE — the char silently vanished; keep ✓ out of all reportlab strings).
